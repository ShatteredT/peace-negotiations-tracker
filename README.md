# Peacetalk Tracker

Peacetalk Tracker — навчальний прототип для діахронічного аналізу новин про мирні переговори
Україна–Росія у 2022–2026 роках. Система оцінює матеріали за чотирма вимірами — дипломатія,
безпека, територіальні питання та гуманітарний вимір — і показує зміну оцінок у часі.

Оцінки й підсумки Gemini є допоміжною аналітикою, а не перевіреними фактами, прогнозом
переговорів чи вимірюванням громадської думки. Важливі висновки потребують людської перевірки.

## Можливості

- **Два джерела новин:** BBC News Україна та Радіо Свобода.
- **Selector:** відбирає до 15 релевантних статей на джерело й піврічний період.
- **Analyst:** оцінює статті за чотирма категоріями за шкалою від −1.0 (ескалація) до +1.0
  (компроміс) і повертає confidence для оцінок.
- **Synthesizer:** формує окремий підсумок і анотації для кожного джерела й півріччя.
- **Streamlit UI:** показує окремі лінії джерел, теплову карту оцінок, статті та експертні
  замітки з модерацією офіційних заяв.

## Збір і підготовка корпусів

Аналітичному конвеєру передує збір і підготовка матеріалів із відкритих джерел. На цьому етапі
опрацьовано корпуси порядку **8 тис. статей BBC** і **12 тис. статей Радіо Свобода**. Для BBC
скрипт `scrapers/bbc_script.py` збирає посилання з sitemap, парсить сторінки статей і відбирає
матеріали за тематичними тегами. Для Радіо Свобода посилання отримуються із sitemap, а корпус
фільтрується за ключовими словами в заголовках і тегах та за датою публікації
(`data/RadioSvoboda/filter_script.py`).

Після підготовки широких корпусів Selector виконує семантичний відбір новин про мирні переговори:
по 15 статей кожного джерела на кожне з 10 півріч. У підсумковому наборі для Analyst — 150 статей
BBC і 150 статей Радіо Свобода.

## Дані демонстраційного набору

У репозиторії є санітизований SQLite snapshot `data/demo/peacetalk_demo.db` для відтворюваного
демонстраційного запуску:

| Дані | Кількість |
|---|---:|
| Статті BBC News Україна | 150 |
| Статті Радіо Свобода | 150 |
| Категорійні оцінки | 1200 |
| Підсумки за джерелом і півріччям | 20 |
| Анотації до статей | 80 |

Повні тексти статей у demo snapshot вилучені. Файли корпусу й результатів Selector/Analyst
зберігаються окремо від SQLite snapshot.

## Запуск демонстраційного застосунку

Потрібен Python 3.11 або сумісний із залежностями проєкту.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:PEACETALK_DEMO_MODE = "true"
python -m streamlit run src/ui/app.py
```

Демо читає snapshot із репозиторію через тимчасову робочу копію. Зміни, зроблені в UI під час
запуску, не переносяться назад у snapshot.

## Архітектура

| Компонент | Основні файли | Призначення |
|---|---|---|
| Selector | `src/agents/selector_optimized.py` | Відбір матеріалів за джерелом і півріччям |
| Analyst | `src/agents/analyst_agent.py`, `src/agents/analyst_schemas.py` | Структуровані оцінки статей |
| Synthesizer | `src/agents/synthesizer_agent.py`, `src/agents/synthesizer_schemas.py` | Source-specific підсумки й анотації |
| UI | `src/ui/app.py`, `src/ui/charts.py` | Дашборд, порівняння джерел і робота із замітками |
| Схема БД | `scripts/init_db.py`, `scripts/migrate_v2.py`, `scripts/migrate_v3.py` | SQLite та міграції до схеми v3 |
| Демо-БД | `data/demo/peacetalk_demo.db` | Санітизований snapshot для демо |

SQLite-схема v3 зберігає джерело для експертних заміток, підсумків і анотацій. Унікальний
підсумок визначається парою «джерело/півріччя». Старі записи підтримуються міграціями зі схем
v1 та v2.

Агенти використовують Gemini API через `google-genai`. Ключ API читається з `GEMINI_API_KEY`;
назви моделей конфігуруються змінними `SELECTOR_MODEL`, `ANALYST_MODEL` і `SYNTHESIZER_MODEL`.
Значення за замовчуванням задані в `src/config.py`. UI для перегляду демонстраційних даних
не потребує виклику Gemini.

## Тести

```powershell
python -m pytest
python -m flake8 src/ tests/ --select=E9,F63,F7,F82
```

Тести перевіряють схеми й міграції БД, оцінювання, підсумки за джерелами, графіки, модерацію
заміток та UI. Виклики Gemini API у тестах замінено контрольованими відповідями.
